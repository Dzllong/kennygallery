# KennyGallery

KennyGallery is a desktop visual reference organizer developed
as an independent personal project.

The application is currently under development. Its current
Pinterest search tool supports image-based visual search,
viewing results, opening original source websites, and downloading images.

Planned Pinterest account integration will let users authorize
through OAuth, browse their accessible boards and board sections,
and explicitly save an existing Pin to a destination they select.
This account integration is not yet available.

KennyGallery is an independent application and is not affiliated
with or endorsed by Pinterest.
