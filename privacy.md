# Privacy Policy

Last updated: October 31, 2026

KennyGallery is an independent desktop application under development.

## Image search

When you initiate an image search, the selected image is processed
by the application and sent to Pinterest's visual search service.
Pinterest receives and processes this request under its own policies.

The application also requests search results and image files
from Pinterest and the image hosts referenced in those results.

## Local data

Search history is held in memory during the current application session.
Images you choose to download are saved to the local download folder.
You can delete downloaded files directly from your computer.

## Pinterest accounts

The current version opens Pinterest login and saving pages
in your external browser. It does not collect Pinterest passwords
or read browser session cookies.

Direct account integration through OAuth is planned but is not
yet available. This policy will be updated before that feature
is made available to describe authorization data storage and deletion.

## External websites

Links may open Pinterest or original source websites.
Those services have their own privacy policies.

## Website hosting

This website is hosted on GitHub Pages. GitHub may process
visitor information, including IP addresses, under its privacy statement.
